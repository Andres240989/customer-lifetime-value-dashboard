# Customer Lifetime Value Analytics Dashboard
**English version first — Spanish version at the end**


## Project Overview

This project is an **interactive dashboard developed with Streamlit** designed to analyze customer value and support commercial decision-making.

The dashboard uses **Net Value (Revenue - Cost)** to segment customers into three categories:

* **High Value:** high-value customers.
* **Medium Value:** medium-value customers.
* **Low Value:** low-value customers.

Based on this segmentation, the dashboard helps identify commercial opportunities and develop differentiated strategies by customer segment and acquisition channel.

## Business Questions

The dashboard is designed to answer the following business questions:

1. **Which channel generates the highest revenue?**
2. **Which customer segment generates the highest revenue?**
3. **How many customers belong to each segment within each channel?**
4. **Which customers are classified as Low Value?**
5. **What commercial opportunities exist to increase the value of Low Value customers?**
6. **What retention strategies can be implemented for each channel?**

## Key Features

### Revenue Analysis

The dashboard allows users to compare **revenue generated by channel and customer segment**, making it easier to identify the channels and customer groups with the highest economic contribution.

### Customer Segmentation

Customers are classified according to their **Net Value**, allowing the identification of customers with higher and lower economic contributions.

### Channel Analysis

The dashboard shows the distribution of **High Value, Medium Value, and Low Value customers across each channel**, helping identify where each customer segment is concentrated.

### Low Value Customer Identification

The dashboard allows users to drill down into customers classified as **Low Value**, providing relevant information to prioritize commercial actions and develop customer growth strategies.

### Commercial Strategies

Based on customer segmentation, the dashboard provides **differentiated commercial recommendations by channel and customer segment**, with a particular focus on retention and customer development strategies for Low Value customers.

## Methodology

Customer segmentation is based on:

**Net Value = Revenue - Cost**

Customers are classified using Net Value percentiles:

* **High Value:** Net Value above the 75th percentile.
* **Medium Value:** Net Value between the 25th and 75th percentiles.
* **Low Value:** Net Value at or below the 25th percentile.

This methodology is intentionally simple and is designed to provide an initial customer classification that can be used to support commercial decision-making.

## Business Value

The purpose of this dashboard is not only to visualize customer data, but to **turn customer data into actionable commercial insights**.

Identifying Low Value customers allows businesses to prioritize retention and customer development efforts, while channel-level analysis helps adapt commercial strategies according to the behavior observed across acquisition channels.

The dashboard therefore acts as a decision-support tool to answer three key questions:

**Where is value being generated?**

**Which customers require attention?**

**What commercial actions can be taken to increase customer value?**




# Customer Lifetime Value Analytics Dashboard

## Descripción del proyecto

Este proyecto consiste en un **dashboard interactivo desarrollado en Streamlit** que permite analizar el valor de los clientes y apoyar la toma de decisiones comerciales.

El dashboard utiliza el **Net Value (Revenue - Cost)** para segmentar los clientes en tres categorías:

* **High Value:** clientes de alto valor.
* **Medium Value:** clientes de valor medio.
* **Low Value:** clientes de bajo valor.

A partir de esta segmentación, la herramienta permite identificar oportunidades comerciales y establecer estrategias diferenciadas por segmento y canal.

## Preguntas de negocio

El dashboard busca responder las siguientes preguntas:

1. **¿Qué canal genera mayores ingresos?**
2. **¿Qué segmento de clientes genera mayores ingresos?**
3. **¿Cuántos clientes pertenecen a cada segmento dentro de cada canal?**
4. **¿Quiénes son los clientes clasificados como Low Value?**
5. **¿Qué oportunidades comerciales existen para incrementar el valor de los clientes Low Value?**
6. **¿Qué estrategias de retención pueden implementarse en cada canal?**

## Funcionalidades principales

### Análisis de ingresos

Permite comparar el **Revenue generado por cada canal y segmento**, facilitando la identificación de los canales y grupos de clientes con mayor contribución económica.

### Segmentación de clientes

Los clientes son clasificados utilizando el **Net Value**, permitiendo identificar aquellos con mayor y menor contribución económica.

### Análisis por canal

El dashboard muestra la distribución de clientes **High Value, Medium Value y Low Value dentro de cada canal**, permitiendo identificar dónde se concentra cada segmento.

### Identificación de clientes Low Value

La herramienta permite profundizar en los clientes clasificados como **Low Value**, mostrando información relevante para priorizar acciones comerciales y desarrollar estrategias de crecimiento.

### Estrategias comerciales

A partir de la segmentación, se generan **recomendaciones comerciales diferenciadas por canal y segmento**, con especial énfasis en estrategias de retención y desarrollo de clientes Low Value.

## Metodología

La segmentación se realiza utilizando:

**Net Value = Revenue - Cost**

Los clientes son clasificados mediante percentiles de Net Value:

* **High Value:** Net Value superior al percentil 75.
* **Medium Value:** Net Value entre los percentiles 25 y 75.
* **Low Value:** Net Value inferior o igual al percentil 25.

Esta metodología es intencionalmente sencilla y tiene como objetivo proporcionar una primera clasificación de los clientes que pueda ser utilizada para orientar decisiones comerciales.

## Valor para el negocio

El objetivo del dashboard no es únicamente visualizar información, sino **convertir los datos de clientes en acciones comerciales**.

La identificación de clientes Low Value permite priorizar esfuerzos de retención y desarrollo comercial, mientras que el análisis por canal facilita adaptar las estrategias según el comportamiento observado en cada medio de adquisición.

De esta manera, el dashboard funciona como una herramienta de apoyo para responder **dónde se genera el valor, qué clientes requieren atención y qué acciones comerciales pueden implementarse para incrementar el valor del cliente.**
